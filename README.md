# Tap Homebrew da PKI Tecnologia

```bash
brew install pkitecnologia/tap/agentes
agentes instalar
pki
```

`agentes` instala e atualiza a frota de agentes da PKI Tecnologia no Claude Code. O conteúdo da frota fica num repositório privado; é preciso ser membro da organização `pkitecnologia` no GitHub.

Para atualizar: `brew upgrade agentes` e, quando a frota avisar de plugin novo, `agentes instalar` de novo.
